# 천안의 맛있는 보물! — 인터랙티브 웹 프레젠테이션

## 원본 안내
첨부된 PPT는 **천안시 청년정책**이 아니라 **천안의 맛있는 보물! (호두과자·배·오이·멜론)** 8장입니다. 본 웹사이트는 실제 첨부 원본의 내용을 변환했습니다.

## 실행
- `index.html`을 브라우저에서 열면 됩니다. 별도의 서버, 데이터베이스, 빌드 과정이 없습니다.
- GitHub 저장소의 최상위 경로에 `index.html`, `styles.css`, `script.js`, `assets/`, `original/`을 올립니다.
- GitHub 저장소 Settings → Pages → Deploy from a branch → `main` / `(root)` 선택 → Save.
- 배포 주소: `https://<사용자명>.github.io/<저장소명>/`

## 조작
- 상단 목차, 하단 이전/다음 버튼으로 이동
- 데스크톱: 좌/우 화살표, 위/아래 화살표, PageUp/PageDown, Space, Home/End, 휠
- 모바일: 좌우 스와이프
- ▦ : 전체 슬라이드 썸네일 / ◩ : PPT 원본 디자인 보기 / ☷ : 발표자 노트 / ⛶ : 전체화면
- 이미지, 발표자 노트 및 출처는 모두 업로드한 원본에서 가져왔습니다.

## 파일
- `index.html`: 웹 슬라이드의 콘텐츠와 구조
- `styles.css`: 반응형 화면 및 애니메이션
- `script.js`: 이동, 인터랙션, 발표자 노트
- `assets/`: 원본 PPT에 포함된 캐릭터 이미지/GIF
- `original/`: 원본 PPT 슬라이드 8장의 고해상도 렌더 이미지
- `asset-map.json`: PPT 슬라이드별 이미지 파일 대응표

외부 CDN/웹폰트 없이 작동합니다. GitHub Pages는 대소문자를 구분하므로 폴더명과 경로를 그대로 유지하세요.
